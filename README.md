A make.fun bounty entry: one fortune cookie message for a software engineer, written by a program to `/output/entry.txt`.

> A stranger will fix your bug in one line. You will spend a week understanding why it works.

Run with `node main.ts` (Node 22). The entry is a single line of at most 120 characters, as the competition gate requires.
